# BCC Universal Converter 1.0.1-rc4

UI hardening and bounded large-workload processing candidate. Workspace, notification and command palette transitions follow the Windows client-area animation preference. Narrow windows gain adaptive home cards, wrapping update actions, stacked PDF, OCR and Print panels, and adaptive Scan settings. Recent history and the Convert file list have bounded scroll areas; the Convert queue now virtualizes visible rows.

OCR processes pages one at a time, writes text incrementally, checks temporary and output disk space, and applies a bounded timeout to each page plus a job watchdog. The hard cap is 250 pages; 100 scanned pages and 250 digital pages have been exercised. The ordinary conversion queue uses backpressure. The image engine decodes frames individually for separate outputs and limits multi-page TIFF memory. Resource failures have specific English and Turkish messages.

The output root remains under the user's control. Word-to-PDF, PDF-to-Word, images-to-WebP, OCR and PDF optimization results use operation folders; collisions receive distinct names without replacing an existing result. If the selected root becomes unavailable, the application reports the condition and does not silently write to a different folder. Batch work remains cancellable, and temporary work owned by a failed or cancelled job is cleaned up.

Resource guards remain in place. PDF input size, page raster dimensions, OCR text output, image frame size, multi-frame TIFF decoded pixels and conversion concurrency have explicit bounds. A document beyond a hard resource bound receives a specific error where available; the application does not claim unlimited processing. The scanner and printer still depend on physical device acceptance outside this release run. The full physical display scale matrix and mixed-scale multi-monitor setup remain outside the available local hardware.

The signed update trust root is unchanged. Physical high-DPI and multi-monitor combinations outside the available test machine remain unverified.
